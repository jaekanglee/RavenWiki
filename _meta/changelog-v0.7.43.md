# raven v0.7.43 — 대시보드 헤더 내 현재 활성 보관소 인디케이터 추가 및 그래프 이동 오류 수정

> **핵심**: 사용자가 대시보드에서 작업 중인 보관소를 직관적으로 인지할 수 있도록 대시보드 헤더에 활성 보관소 인디케이터를 추가하였으며, 연결 그래프 화면에서 문서를 클릭해 이동할 때 `slug` 필드가 존재하지 않아 `undefined` 페이지로 네비게이션되던 오류를 수정했습니다.

릴리스 일자: 2026-07-01
이전: v0.7.42

---

## 1. 배경 및 기획

* **보관소 인디케이터 추가**:
  * **상황**: 대시보드의 사이드바 외에는 현재 어떤 보관소(Vault)를 보고 있는지 즉각 확인할 수 있는 글로벌 표시 장치가 없었습니다.
  * **해결 방안**: 로고(`Raven`) 바로 옆에 구분선 및 칩 형태의 현재 활성 보관소 이름 인디케이터를 배치하고, 클릭 시 `/vault/manage` 페이지로 이동할 수 있는 편의 기능을 추가했습니다.
* **그래프 문서 이동 오류 수정**:
  * **상황**: 그래프 화면 우측 상세 정보 패널이나 핵심 허브, 고립 문서 목록 등에서 노드를 클릭해 문서를 열면 `page undefined not found in vault` 오류가 발생했습니다.
  * **원인**: 백엔드 API `/api/vaults/{name}/graph`가 `nodes` 응답에서 `slug` 대신 `id` 필드로만 식별 정보를 전달하여, 프론트엔드가 기대하는 `node.slug` 참조 시 `undefined`가 할당되었습니다.
  * **해결 방안**: API 응답의 각 노드에 `slug` 필드를 명시적으로 부착하고, 프론트엔드의 `GraphPage.tsx` 컴포넌트에서도 `node.slug ?? node.id`를 사용하여 예외 상황에 대처하는 안전장치(Fallback)를 설계했습니다.

## 2. 변경 사항

### 2-1. 대시보드 레이아웃 헤더 영역 수정 (`dashboard/src/components/Layout.tsx`)
* 로고(`Link` 컴포넌트) 우측에 `vault` 상태가 존재할 때 렌더링되는 활성 보관소 표시용 컴포넌트 구조를 추가했습니다.
* 보관소 관리로의 이동을 용이하게 하기 위해 `<Link to="/vault/manage">`로 감싸고, CSS 클래스 `active-vault-chip`을 부여했습니다.

### 2-2. 글로벌 스타일 시트 클래스 정의 (`dashboard/src/styles/globals.css`)
* `.active-vault-chip` 클래스를 통해 HSL HSL 색상 변수 및 폰트 변수를 사용하는 둥근 배지 형태의 스타일을 정의했습니다.
* hover 및 active 선택자에 맞춰 1px 위로 뜨는 마이크로 애니메이션(`transform`, `box-shadow`, `border-color`) 트랜지션을 적용해 프리미엄 인터랙션을 구현했습니다.

### 2-3. 그래프 페이지 문서 네비게이션 폴백 설계 (`dashboard/src/routes/GraphPage.tsx`)
* `GraphPage.tsx` 내에서 `node.slug`를 직접 탐색하던 부분을 `node.slug ?? node.id`로 래핑하여, API로부터 `slug`가 누락되거나 다른 필드로 수신되더라도 안정적으로 해당 페이지 슬러그를 복원할 수 있도록 개선했습니다.

### 2-4. 그래프 API 노드 데이터 필드 보강 (`raven/api/server.py`)
* `/api/vaults/{name}/graph` 엔드포인트 내의 DB 조회 결과 매핑(`nodes`) 부분 및 rglob fallback 매핑 부분 모두에 `slug` 필드를 명시적으로 보강하여 반환하도록 조치했습니다.

### 2-5. 멀티 에이전트 협업 가이드 추가 (`raven/core/templates/agent/PROJECT-WORKFLOW.md`)
* 단일 보관소 내에서 다수의 에이전트 프로필이 동시에 또는 독립적으로 일할 때 발생할 수 있는 충돌을 미연에 방지하기 위해, 폴더 기반 격리, 동시성 락/백오프 대응, 공유 `log.md` 작성 규약, 그리고 공통 스키마 준수 원칙을 설명하는 섹션(9. 멀티 에이전트 협업 규칙)을 신설하고 부트스트랩 템플릿에 추가했습니다.
