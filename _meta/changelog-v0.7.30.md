# raven v0.7.30 — 지식 정원(Gardening) 고립 문서 수동 연결 기능 구현

> **핵심**: 지식 연결 추천 후보가 없거나, 사용자가 직접 수동으로 지식 구조를 엮고 싶을 때를 대비해 **고립 문서 수동 연결(Manual Connection)** 기능을 탑재했습니다. 고립된 문서(Orphan Pages) 카드 하단에 수동 연결 폼을 제공하여, 보관소 내의 모든 문서 목록 중 대상을 선택해 쉽고 유기적으로 지식을 연동할 수 있도록 정원 관리 편의성을 확장했습니다.

릴리스 일자: 2026-07-01
이전: v0.7.29

---

## 1. 변경 사항

### 1-1. Orphan Pages 수동 연결(Manual Connect) UI 및 상태 구축
* **`dashboard/src/routes/GardenPage.tsx`**:
  * 보관소 전체 문서 목록을 획득하기 위해 `fetchPages` 헬퍼 함수를 추가 import했습니다.
  * 보관소 내 전체 페이지 정보를 저장하는 `allPages` 상태를 추가하고, 데이터 갱신 시 최신 전체 페이지 목록을 백엔드로부터 캐싱하도록 구현했습니다.
  * 어떤 고아 문서의 수동 연결 창이 활성화되었는지 식별하는 `activeManualConnect` 상태와 선택한 수동 연결 타겟 slug를 추적하는 `manualTargetSlug` 상태를 구축했습니다.
  * 각 고아 문서 카드 하단에 `🔎 수동 연결...` 토글 버튼을 추가하여, 클릭 시 select 드롭다운으로 자기 자신을 제외한 전체 문서 목록 중 하나를 골라 `연결`할 수 있도록 폼 레이아웃을 제공했습니다.
  * 연결 시 기존 연결 헬퍼(`handleConnectLink`)가 호출되어 대상 문서 하단에 고아 문서 링크를 안전하게 연결하고 보관소 통계를 동적으로 재계산하게끔 매끄럽게 흐름을 연결했습니다.
