# raven v0.7.64 — WorkspacePage 좌측 패널 탭 분리 (워크스페이스 / 변경사항)

> **핵심**: v0.7.63에서 우측 패널 탭 분리를 시도했으나, 좌측 패널에 파일 트리와 Git 변경사항 목록이 상하(stacked)로 고정되어 있어 화면 공간이 협소하고 UX가 복잡했습니다. v0.7.64에서는 **좌측 패널 자체에 탭(`activeLeftTab`)을 구현**하여 `[🌳 워크스페이스]`와 `[📋 변경사항]`을 분리했습니다. 우측 패널의 독립 탭(`activeTab`)을 제거하고 좌측 탭과 상태를 동기화하여 화면 넓이를 넓게 확보하고 런타임/빌드 에러를 완벽히 해결했습니다.

릴리스 일자: 2026-07-03
이전: v0.7.63

## 1. 변경 사항

### 1-1. `WorkspacePage.tsx` — 좌측 패널 탭 모드 및 상태 정리

- **`activeLeftTab` 기반 렌더링**:
  - 좌측 영역 상단에 `[🌳 워크스페이스]` 및 `[📋 변경사항]` 탭 헤더 추가.
  - `activeLeftTab === "workspace"`: 워크스페이스 OS 트리(read-only) 노출 (기존 상하 stacked 구조에서 탈피하여 화면 세로 공간을 flex: 1로 확보).
  - `activeLeftTab === "changes"`: Git 변경 파일 목록 노출.
- **우측 패널 탭(`activeTab`) 제거**:
  - 이전 에이전트의 작업 중단으로 누락되었던 `activeTab` 상태 정의를 완전히 정리하고, 우측 패널의 본문 분기를 좌측의 `activeLeftTab` 상태와 동기화시켰습니다.
  - `activeLeftTab === "workspace"`: 선택 파일 **미리보기** (binary 안내 포함).
  - `activeLeftTab === "changes"`: Git **Diff 뷰어**.

### 1-2. 핸들러 및 자동 전환 싱크

- 트리 디렉토리 클릭 / 트리 파일 클릭 / 트리 상위 폴더 이동 시: `setActiveLeftTab("workspace")` 자동 호출.
- Git 변경사항 목록의 파일 클릭 시: `setActiveLeftTab("changes")` 자동 호출.
- 이를 통해 사용자가 탭을 수동으로 전환하지 않고 파일 목록에서 항목을 클릭하는 것만으로 우측 뷰어가 알맞은 모드로 즉시 자동 스위칭됩니다.

## 2. UX 시나리오 (검증용)

```
1. /workspace 진입 → 좌측에 [🌳 워크스페이스] 탭이 켜진 상태로 트리 노출
2. 트리에서 파일(.md 등) 클릭 → 우측에 미리보기 렌더링
3. 좌측에서 [📋 변경사항] 탭 수동 클릭 → Git 변경 파일 목록으로 전환
4. 변경 파일 목록 중 하나 클릭 → 우측에 Git Diff 뷰어 렌더링
5. 다시 트리에서 파일을 클릭하는 액션 발생 → [🌳 워크스페이스] 탭으로 자동 스위칭되며 미리보기 노출
```
