# raven v0.7.33 — 린트 페이지 빠른 대화형 필터(Fast Filter) 구현

> **핵심**: 사용자가 지식 보관소의 린트 에러들을 종류별 혹은 심각도별로 기민하게 탐색하고 정리할 수 있도록 **린트 페이지 빠른 대화형 필터(Fast Filter)**를 구축했습니다. 심각도 카드(SeverityCard)와 14개 린트 규칙 바 차트의 행들을 클릭 한 번으로 토글할 수 있는 인터렉티브 필터로 진화시켜, 린트 확인 및 지식 정돈 피드백 루프를 대폭 개선했습니다.

릴리스 일자: 2026-07-01
이전: v0.7.32

---

## 1. 변경 사항

### 1-1. 심각도 카드(SeverityCard) 대화형 필터 연동
* **`dashboard/src/routes/LintPage.tsx`**:
  * 상단의 3대 등급 요약 카드(`critical`, `warning`, `info`) 클릭 시 해당 심각도가 토글되어 이슈 리스트를 필터링하도록 이벤트를 바인딩했습니다.
  * 필터가 활성 상태일 때 카드의 테두리가 2px의 테마색(`--color-primary`)으로 볼드 처리되어 시각적 초점을 제공하도록 UI를 개선했습니다.

### 1-2. 14개 린트 규칙 바 차트 대화형 필터 연동
* **`dashboard/src/routes/LintPage.tsx`**:
  * 14개 린트 규칙별 개수 요약 바 차트의 각 행을 클릭 가능한 요소(`cursor: pointer`)로 진화시키고, 클릭 시 해당 체크 아이디(예: `#1`, `#11`) 필터링이 즉각 토글 적용되도록 구현했습니다.
  * 호버 상태에서 부드러운 배경색 피드백을 주며, 활성화된 필터 행에는 `var(--color-surface-soft)` 배경색을 강조 렌더링하여 현재 어떤 린트 룰을 집중 진단 중인지 명확한 맥락을 파악할 수 있게 보완했습니다.
