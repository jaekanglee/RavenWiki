# raven v0.7.41 — Docker 컨테이너 내 볼트 파일 경로 호스트 매핑 처리

> **핵심**: Docker 컨테이너 환경에서 볼트 파일을 조회할 때, 컨테이너 내부 마운트 경로인 `/vaults/...` 대신 사용자의 실제 호스트 절대 경로(예: `/Users/jaekanglee/Raven/...`)로 변환하여 출력하도록 백엔드 API를 개선했습니다.

릴리스 일자: 2026-07-01
이전: v0.7.40

---

## 1. 배경 및 기획

* **상황**: 문서 뷰어 상단에 마크다운 파일의 전체 경로를 표시하도록 기능을 추가했으나, Docker 컨테이너 내에서 구동 시 컨테이너 내부 마운트 경로인 `/vaults/hermes-infra/content/...`로 표시되었습니다.
* **사용자 요구**: 호스트 PC의 실제 경로인 `/Users/jaekanglee/Raven/...` (혹은 `~/Raven/...`) 형태로 표기되는 것이 직관적입니다.
* **해결 방안**: Docker 구동 시 `.env` 파일에 기록된 `RAVEN_VAULTS_DIR` 환경변수를 백엔드가 감지하여, 파일 경로의 `/vaults` 접두사를 호스트 실제 디렉토리 경로로 교체해 반환하도록 보완했습니다.

---

## 2. 변경 사항

### 2-1. 백엔드 페이지 조회 API 경로 매핑 로직 추가 (`raven/api/server.py`)

* **호스트 경로 복원**: `os.environ.get("RAVEN_VAULTS_DIR")` 환경변수가 존재하고 파일 절대 경로가 `/vaults`로 시작하는 경우, 접두사를 해당 호스트 디렉토리 경로로 치환하여 `file_path` 응답을 반환합니다.
* **로컬/Docker 호환성 보장**: 로컬에서 Docker 없이 구동할 때는 `/vaults` 접두사가 없으므로 치환이 일어나지 않고 실제 로컬 파일 경로가 온전히 유지됩니다.
