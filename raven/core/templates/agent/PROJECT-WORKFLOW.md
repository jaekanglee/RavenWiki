# Project Workflow — 호환 안내

`PROJECT-WORKFLOW.md`는 이전 Lite bootstrap의 정책 문서 이름이다. 새 vault에는 자동 주입되지 않으며, Raven의 현재 기술 계약은 [`RAVEN-CONTRACT.md`](RAVEN-CONTRACT.md)와 [`SCHEMA.md`](SCHEMA.md)에 있다.

에이전트 역할, 저장·검토 기준, 글쓰기 방식, 큐레이션 방식은 Raven이 정하지 않는다. vault 운영자가 소유한 별도 정책을 따르며, 해당 정책이 없다면 작업 지시를 준 사람에게 확인한다.
